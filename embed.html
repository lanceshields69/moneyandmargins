Embed a race card

Each race card on Money & Margins can be placed on another site. Paste the embed code for a state's race from its share and embed panel, and the card appears where you paste it.

What the embed loads

The code loads one script, moneyandmargins.app/embed/mm-card.js. That script places a card in a frame that loads moneyandmargins.app/embed-card.html. The card is drawn from the same data as the map, and it is refreshed each time the site is updated. Nothing else is loaded from your page.

Embed code

<div data-mm-card="TX" data-mm-race="2026-SEN-TX"></div>
<script async src="https://moneyandmargins.app/embed/mm-card.js"></script>

Change the state code to embed another race.

Report a problem

If a number on an embedded card looks wrong, email lance@lanceshields.design and include the page the card is on and the race. Reports are reviewed, and corrections are made to the site's data.
